# Rock Paper Scissors

This is a simple Python game I created while learning Python.

The player chooses Rock, Paper, or Scissor, and the computer randomly selects a move. The program compares both choices and displays the result.

## What the program does

* Takes the user's choice
* Randomly selects the computer's choice
* Compares the two choices
* Displays whether the user wins, the computer wins, or the game is a tie
* Handles invalid choices

## Technologies Used

* Python

## How to Run

Open the project folder in the terminal and run:

```
py rock_paper_scissors.py
```
