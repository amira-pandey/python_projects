# Room Expense Calculator

This is a simple Python program I created while learning Python.

The program calculates the total room or flat expenses and determines how much each person needs to pay.

## What the program does

* Takes the hostel or flat rent
* Takes the amount spent on food
* Takes electricity units used
* Takes the electricity charge per unit
* Takes the number of people sharing the room or flat
* Calculates the electricity bill
* Calculates the amount each person needs to pay

## Technologies Used

* Python

## How to Run

Open the project folder in the terminal and run:

```
py room_expense_calculator.py
```
