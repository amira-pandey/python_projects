# Python Quiz

This is a simple Python quiz program I created while learning Python.

The program asks multiple-choice questions about basic Python concepts and checks the user's answers.

## What the program does

- Shows Python questions with four options
- Takes the user's answer
- Checks whether the answer is correct
- Keeps track of correct and wrong answers
- Calculates the final score
- Calculates the percentage
- Shows a result based on the score
- Handles invalid answers

## Technologies Used

- Python

## How to Run

Open the project folder in the terminal and run:

    py python_quiz.py
