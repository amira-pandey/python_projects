# Monthly Expense Analyzer

This is a simple Python program I created while learning Python.

The program asks for monthly expenses in different categories and calculates the total expense and daily average.

## What the program does

- Takes the user's name
- Takes food, rent, travel, and other expenses
- Calculates the total monthly expense
- Calculates the average daily expense
- Displays a simple expense report

## Technologies Used

- Python

## How to Run

Open the project folder in the terminal and run:

    py expense_analyzer.py
