# Student Management System

This is a simple Python program I created while learning Python.

The program allows the user to manage basic student information through a simple menu.

## What the program does

- Adds student information
- Displays student information
- Allows the user to update information
- Uses a menu-based system
- Runs in the terminal

## Technologies Used

- Python

## How to Run

Open the project folder in the terminal and run:

    py student_management.py

While making this project, I practiced:

- Lists

- User input
